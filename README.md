# python-basics-25BCON0667-struct-to-dict
Beginner Python Repository: struct-to-dict.py

This repository contains a beginner-friendly Python script that demonstrates how to work with dictionary data structures and formatted string literals (f-strings) in Python.

What the Program Does

The struct-to-dict.py script:

Defines a Python dictionary named student containing key-value pairs for a student's information (name, roll, and marks).

Accesses the values in the dictionary using their respective keys.

Uses an f-string to print the student's name, roll number, and marks to the console.

Formats the marks floating-point value to one decimal place (.1f).

Expected Output

When you run the program, it produces the following output:

Name: Rahul
Roll: 101
Marks: 87.5


How to Run It

Ensure you have Python installed on your system.

Open a terminal or command prompt in the directory containing struct-to-dict.py.

Run the script using the following command:

python struct-to-dict.py


Learning Objective

This script is designed to help beginners understand:

How to declare and structure data using Python dictionaries (dict).

How to access dictionary values using key lookup syntax (student['key']).

How to use formatted string literals (f-strings) for clean variable interpolation and output formatting (such as floating-point precision formatting with :.1f).
